# Play & Learn: Rock, Paper, Scissors in Python

An interactive page for learning Python. Pick a move and watch which lines of the
real Python program run, with a plain-English note at every step.

**Play it:** https://giridharreddy-t.github.io/rps-python-learning-game/

## What you learn
- `main.py`: imports, variables, a `while` loop, f-strings
- `game_logic.py`: functions and `if / elif / else`
- `player.py`: a `while True` loop with input validation
- `computer.py`: the `random` module and lists

## Run the original Python game
```bash
cd original-python
python main.py
```

## Project layout
```
index.html          # the interactive learning page (no build step)
original-python/    # the original command-line game
```
